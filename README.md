# bscs26085_ProductWebsite
Deskwell is a simple product website, showcasing desk accessories like the Mechanical Keyboard, Glide Wireless Mouse, and Halo Monitor Light Bar. The site has three pages — Home, Products, and Contact — and lets users check product availability with a click.
The site was built using HTML for structure, CSS for styling, and JavaScript for interactivity, including a dynamic footer year, availability toggles on the Products page, and a validated contact form.
